# Workshop Studio

Браузерный конструктор для нарезки видео, GIF и изображений для Steam Workshop.

**Открыть конструктор:** https://enroxd1.github.io/workshop-studio/

Хостинг: GitHub Pages, ветка `main`, папка `/docs`. При изменении исходников выполните сборку и сохраните обновлённую папку `docs` в Git — публикация запустится автоматически.

## Возможности

- 1–3 ряда по 5 частей, ширина каждой части — 150 px.
- Высота 150/430/600 px, автоматическая по пропорциям или пользовательская до 1500 px; высота округляется до числа, кратного количеству рядов.
- Масштабирование, перемещение, заполнение или вписывание кадра.
- Выбор фрагмента, 10/15/24/30 FPS, палитра 32–256 цветов, рамки и цветокоррекция.
- GIF-анимация или PNG текущего кадра, ZIP с нумерацией и индивидуальные загрузки.
- Проверка выбранного лимита 5/8 МБ на каждую часть. Превышающие лимит части отмечаются; автоматическое уменьшение качества не применяется.
- Опциональный Steam Hex Patch (последний байт 3B → 21), а также отдельный патчер до 15 GIF.
- Все медиа обрабатываются на устройстве пользователя. Веб-версия загружает шрифт Google Fonts; офлайн-версия полностью автономна.

## Использование

Откройте опубликованный сайт или автономный файл `Workshop-Studio.html` двойным щелчком. Выберите файл, настройте композицию, нажмите «Нарезать и скачать ZIP», распакуйте архив. Загружайте части в Steam по номерам слева направо, затем сверху вниз.

MP4 H.264 и WebM рекомендуются для видео. Поддержка MOV и других контейнеров зависит от браузера и кодека. Звук в GIF не переносится. WebP импортируется как статичное изображение. Максимум 200 МБ на файл и 1200 кадров на экспорт; слишком большие GIF ограничены 16 мегапикселями на кадр. Фон прозрачных изображений при экспорте заполняется тёмным цветом.

Hex Patch меняет завершающий байт и предназначен для специального способа загрузки длинных GIF в Мастерскую; обычный GIF сохраните отдельно. Порядок загрузки и доступность нескольких рядов зависят от возможностей Steam-профиля. Сайт не публикует файлы в Steam автоматически. Правила и лимиты Steam могут меняться.

## Разработка

Нужен Node.js 22+ и pnpm. Исходный код в `src/`, статические ресурсы и готовая сборка в `docs/`.

```text
pnpm install
node build.mjs
node test.mjs
node serve.mjs
```

Откройте http://127.0.0.1:4287/. Для создания автономного HTML:

```text
node offline.mjs /absolute/path/Workshop-Studio.html
```

Статический сайт можно разместить на любом HTTP-хостинге. Сборка включает локальные библиотеки gifenc, gifuct-js и fflate; сервер обработки, FFmpeg и API-ключи не требуются. Лицензии библиотек — в `docs/THIRD-PARTY-LICENSES.txt`.

Функциональный ориентир: https://steamprofile.io/ru/gif-edit . Интерфейс и код реализации самостоятельные.
